## 2. Apigee Analytics Data Collectors (All 18 Captured Metrics)

The gateway populates **18 Data Collectors** on every non-streaming and streaming request so you can build custom Apigee Analytics and Looker Studio reports grouped by **Model**, **Developer**, **User (`dc_identity_user_id`)**, **AI Product Persona (`dc_identity_persona`)**, or **Team/Department (`dc_identity_team`)**—with full visibility into **prompt cache hits, reasoning tokens, and per-token-type USD costs**:

| Data Collector | Type | Flow Variable Source | Description |
| :--- | :---: | :--- | :--- |
| **`dc_prompt_token_count`** | `INTEGER` | `prompt_tokens` / `usage_prompt_tokens` | Total prompt input tokens (`uncached + cache_read + cache_write`). |
| **`dc_uncached_prompt_token_count`** | `INTEGER` | `uncached_prompt_tokens` | Standard uncached prompt input tokens. |
| **`dc_cache_read_token_count`** | `INTEGER` | `cache_read_tokens` | Cached prompt tokens read at the discounted cache-read rate. |
| **`dc_cache_write_token_count`** | `INTEGER` | `cache_write_tokens` | Prompt tokens written to cache. |
| **`dc_thinking_token_count`** | `INTEGER` | `thinking_tokens` | Internal reasoning / chain-of-thought tokens generated by the model. |
| **`dc_completion_token_count`** | `INTEGER` | `completion_tokens` / `usage_completion_tokens` | Total completion output tokens (including reasoning tokens). |
| **`dc_total_token_count`** | `INTEGER` | `usage_total_tokens` | Total tokens consumed (`prompt + completion`). |
| **`dc_tx_uncached_prompt_cost_usd`** | `FLOAT` | `tx_uncached_prompt_cost_usd` | USD cost of uncached prompt input tokens. |
| **`dc_tx_cache_read_cost_usd`** | `FLOAT` | `tx_cache_read_cost_usd` | USD cost of cached prompt tokens read. |
| **`dc_tx_cache_write_cost_usd`** | `FLOAT` | `tx_cache_write_cost_usd` | USD cost of prompt tokens written to cache. |
| **`dc_tx_prompt_cost_usd`** | `FLOAT` | `tx_prompt_cost_usd` | Total input USD cost (`uncached + cache_read + cache_write`). |
| **`dc_tx_completion_cost_usd`** | `FLOAT` | `tx_completion_cost_usd` | Total output USD cost (`completion + thinking`). |
| **`dc_tx_cost_usd`** | `FLOAT` | `tx_cost_usd` | Total transaction USD cost (`tx_prompt_cost_usd + tx_completion_cost_usd`). |
| **`dc_model`** | `STRING` | `model` | Effective backend model that processed the request. |
| **`dc_requested_model`** | `STRING` | `requested_model` | Original client-requested model, alias, or `auto:judge`. |
| **`dc_identity_user_id`** | `STRING` | `identity_user_id` | Authenticated human user (`sub`/`email`), Google Cloud Agent (`principal://` or SA email), or App ID. |
| **`dc_identity_persona`** | `STRING` | `identity_persona` | Mapped AI Product persona (`lead-ai-engineer`, `developer`, etc.). |
| **`dc_identity_team`** | `STRING` | `identity_team` | Department / cost-center / team attribute (`eng-ml`, `project:12345`, or persona fallback). |
